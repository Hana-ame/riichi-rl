# obs v3（牌河顺序平面进主策略）端到端 pilot：实现完成，首轮欠拟合

## 实现（commit 8b5e757 + 本轮修正）

- `obs2.ObsEncoder(order=True)`：22 → **46 平面**（追加四家最近 6 张弃牌位次 one-hot）；
- `net.MahjongNet(in_planes=...)`；`gen_teacher_data --obs-order`；
  `train_teacher_bc` 自动推 in_planes 并存 `{in_planes=46, obs_order=True}`；
  `eval_hanchan` 按 ckpt 自动选 46 平面 encoder；
- 修正两处：① in_planes 公式（x=平面*34+标量26+局势12，touch 单独）② eval 的 encoder
  未带 order（否则 786 维喂 46 平面网络报错）。

## pilot 结果（100 半庄 v3 数据、从零 2 epochs）

| 项目 | 读数 |
|---|---|
| 数据 | `data/teacher47_100_v3.npz`：**208,542 样本 × 1602 维** |
| 参数 | 454,768（v2 为 453,232） |
| val_acc | **0.927**（v2 100h 是 0.962；从零只训 2 epochs，欠拟合） |
| 80 局评测 | **局和牌 26.25%（21/80，座位≈6.56%）** vs 100h_v2 **33.75%（≈8.44%）** |

- 结论：**首轮 obs v3 不优于 v2**，但这是「从零 2 epochs」的欠拟合结果，不是定论；
- 下一步：v3 从零续训到 5–8 epochs（或先 pretrain v3 再 fine-tune），再比较
  局和牌/座位率与「顺序增益」（用 v3 特征重训 opp_shanten 头看 MAE 降幅）。

## 注

- v3 与旧 91 ckpt 完全不兼容；v2 默认仍 22 平面，不影响现有系统。
