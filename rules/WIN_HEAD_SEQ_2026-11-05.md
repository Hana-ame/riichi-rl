# 和牌率预测（AUC≥0.6 验收）：顺序 GRU 达标 0.736

## 实现

`win_head_seq.py`：live 对局 40 局、14,742 样本；逐决策记录 108 维可见统计 +
四家弃牌顺序（各 24 张，pad=34）；标签 = 目标家本局最终和牌（流局=0）；
**按局切分**（修正了随机切分导致 AUC 0.998 的泄漏）。

| 模型 | 特征 | 和牌 AUC |
|---|---|---|
| MLP | 108 维可见统计 | **0.716** |
| **GRU（顺序）** | 108 + 四家弃牌序列 | **0.736** |

- 两者均 ≥0.6 验收线；顺序 GRU 再 +0.020；
- 对比旧 `aux_heads`（replay 数据、按局切分）win AUC 0.572 → 本次 live 数据
  的上下文更完整（含真实巡目/河流/宝牌），AUC 提升到 0.716–0.736；
- 结论：**「和牌率判断」验收达标**（AUC≥0.6）；「牌河顺序→向听增益」仍是 0.013
  <0.2 未达标（两个不同指标，分开判定）。

## 复现

```bash
python win_head_seq.py --deals 40 --epochs 10
```
