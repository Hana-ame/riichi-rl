# 叫牌+打牌「联合训练」pilot（学生 roll-in = 主模型 + 学习叫牌）

## 数据（joint_v1.npz）

- 学生：`100h_v2` + `call_policy_v2`（会叫牌）roll-in；
- 教师：**Suphx 全模型**（discard + chi/pon/kan 三头）在学生的真实状态上打 47 槽标签；
- 采集 200 局（1037s）→ **57,015 样本**：
  tsumo 14（0.02%）、ron 25（0.04%）、riichi 129（0.23%）、
  **pon 524（0.92%）、chi 288（0.51%）** —— 吃碰标签确实进入联合数据。

## 训练与评测

```bash
train_teacher_bc --data data/joint_v1.npz --init teacher47_100h_v2.pt --epochs 2
eval_hanchan --ckpt teacher47_joint_v1.pt --hanchans 10
```

| 项 | 读数 |
|---|---|
| val_acc | **0.811**（100h_v2 0.962 → 掉 15pt） |
| 80 局评测 | **局和牌 5/80 = 6.25%（座位≈1.56%）** |
| 对照 100h_v2 | 33.75%（≈8.44%）→ **严重退化** |

## 结论

**联合训练 pilot 失败**：用 Suphx 硬标签在学生会叫牌的状态上训 47 槽策略，val_acc 与
实战双崩（6.25%）。原因：Suphx 动作→我们 47 槽的映射有损（之前 600 局 DAgger 也 28.75%），
且 57k 样本/2 epochs 不足以覆盖「叫牌后牌型」的状态分布。

→ 副露策略仍未达标；继续做需要 **动作空间无损映射** 或 **在联合状态上直接用我们自己的
规则教师（吃碰杠判定）+ 主策略 RL 联合优化**，而不是 Suphx 硬标签。
