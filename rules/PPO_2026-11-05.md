# PPO 微调试验记录（从 100h_v2 起步，iter75 中段）

## 训练

```bash
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 python train_hanchan.py \
  --init checkpoints/teacher47_100h_v2.pt \
  --ppo-epochs 2 --clip 0.2 --iters 100 --hanchans 8 \
  --lr 1e-5 --entropy 0.005 --shanten-weight 0.3 \
  --out checkpoints/teacher47_ppo_v1.pt
```

## 中段评测（每局每座位口径）

| 模型 | 局和牌（80 局） | 座位≈ | 同池 60 局/席：听牌 | 座位和牌 | 座位放铳 |
|---|---|---|---|---|---|
| teacher47_100h_v2（基线） | 33.75%（27/80） | ≈8.44% | 30.0% | 6.7% | 8.3% |
| PPO it35 | 31.25% | ≈7.81% | 25.0% | 5.0% | 8.3% |
| **PPO it75** | **23.75%（19/80）** | **≈5.94%** | **16.7%** | **0.0%** | **10.0%** |

- 随迭代单调恶化（it35→it75 局和牌 31.25%→23.75%），与 REINFORCE pilot 同方向：
  **从强 BC 起步做小步 RL，仍会把策略带向保守弃和**；
- 原因判断：奖励尺度/价值函数与 BC 策略不匹配（R≈+0.018、vloss 从 1.9→0.03 收敛过快），
  策略被 value baseline 主导而放弃进攻。
- 结论：**PPO 本配置判负**（终评 iter100 预计同样低于基线，跑完补数）；
  后续若要 RL，需重新设计奖励（提高和牌/立直权重、降低防守）或从随机初始化重训。

## 影响

- 当前最佳仍是 `teacher47_100h_v2`（局和牌 33.75%/座位≈8.44%、同池 6.7%/8.3%），
  **硬门槛（座位和牌 15–25%、放铳 9–20%）仍未达到**；
- 下一步被验证有效的只剩「外部 Suphx 全模型蒸馏（弃牌+叫牌）」或直接用外部模型。
