# 牌河顺序→对手向听：GRU 序列模型 vs MLP 基线（2026-11-05）

## 实现

`opp_shanten_gru.py`：
- 数据：live 对局 40 局，逐决策记录观察者/目标、**四家弃牌顺序**（各 24 张，pad=34）、
  108 维可见统计；14,742 样本；
- 模型：tile embedding(16) → GRU(128) → 与 108 维拼接 → 向听 7 分类 + 听牌二分类；
- 对照：同标签的纯 108 维 MLP。

## 结果

| 模型 | 向听 MAE | 听牌 AUC |
|---|---|---|
| mlp_base108（无顺序） | 0.339 | 0.996 |
| **gru_order（真实顺序）** | **0.326** | 0.999 |

**顺序 GRU 相对无顺序 MLP：MAE 只降 0.013（验收线 0.2）→ 仍未达标。**

## 结论

- 即使换成序列模型（GRU + 真实弃牌顺序），牌河顺序对「对手向听」的增量仍然很小；
- 原因判断：可见信息（牌河 counts + 巡目 + 立直）已包含大部分可推断信息；顺序的
  额外信息被切牌随机性/样本量稀释；
- 下一步（若要继续）：加大数据到 300–500 局、把顺序放进**主策略 obs** 端到端训练，
  而不是单独预测头；或改用 Transformer + 位置编码。
