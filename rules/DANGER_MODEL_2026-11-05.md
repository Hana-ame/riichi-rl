# 危险张升级：从「对手持有概率」到「对手和牌张概率」（2026-11-05）

> 审阅建议：危险分升级为「对手和牌张概率」再 500+ 局验证。

## 模型

`danger_model.py::DangerNet`（108 维 → 256 → 128 → 34 sigmoid）：

- **输入**（可见信息，与 `opponent_model` 同一套）：自家手牌 counts + 目标家
  牌河 counts + 其它两家牌河聚合 + 目标家副露数/立直/已打张数 + 巡目/墙余/宝牌；
- **输出**：34 维「该对手每张牌是他的**和牌张**的概率」；
- **标签**（从观战数据上帝视角构造）：目标家门前（副露=0）且手牌 13 张时，
  若 `ref_shanten == 0`，用 `can_win_with` 枚举全部和牌张 → 34 维 0/1；
  非听牌全 0；14 张/有副露的样本跳过。
- 训练：703 局 selfplay → **65,696 样本**（正样本率 0.2%，`pos_weight≈406`），
  CPU 8 epochs；验证集听牌样本 n=413，**top5 命中 0.882**（听牌样本里命中和牌张）。

## 用于危险分

`HybridShantenWinDangerAgent`（`hybrid_agents.py`，前缀 `hybridw:`）：

```
danger[t] = Σ_opp 威胁权重(立直=1.0 / 未立直=0.25) × P(opp 的和牌张 = t)
```

弃牌仍以**代码向听最小**为主，同向听档内用上述危险分躲牌；立直/和牌/副露/
响应仍由模型 argmax。

## 验证（与 hybrid / hybridd 同批同局占座，500 局）

（结果见下一节，跑完回填；脚本 `danger_validate.py --games 500`）

## 500 局验证结果（三臂同批同局占座；第四席 greedy_tenpai）

| Agent（危险度来源） | 局数 | 和牌率 | 场均得分 | 放铳率 |
|---|---|---|---|---|
| hybrid（无危险度） | 500 | 9.2% | −484.7 | 7.6% |
| hybridd（对手**持有**概率） | 500 | **10.4%** | **+774.4** | **5.8%** |
| hybridw（对手**和牌张**概率，本轮新） | 500 | 7.2% | −637.6 | 6.6% |
| greedy_tenpai（规则） | 500 | 8.6% | −604.1 | 5.8% |

放铳率差（相对 hybrid）：
- hybridd：**−1.80 pt**，95% CI [−4.90, +1.30] → **INCONCLUSIVE**
- hybridw：**−1.00 pt**，95% CI [−4.18, +2.18] → **INCONCLUSIVE**

## 结论（诚实）

1. **升级方向失败**：用「对手和牌张概率」（DangerNet）的 hybridw 表现比原
   hybrid 更差（和牌 7.2% vs 9.2%、场均 −638 vs −485）——该模型虽然听牌样本
   top5=0.882，但作为弃牌 tie-break 信号太稀疏/噪声大，反而拖累牌效。
2. **原「持有概率」danger（hybridd）仍是最好的一档**：和牌 +1.2pt、场均 +1259、
   放铳 −1.8pt；但 **500 局仍不显著**（CI 跨 0）。按 7.6%→5.8% 的差，约需
   **1200+ 局/臂**（或同局配对 McNemar）才有统计把握。
3. 因此：**危险张「让放铳率下降」尚未获得统计证据**，不能标记完成；但
   hybridd 作为当前最佳混合 Agent 可以保留（场均明显更好）。
4. `danger_model.pt` 保留但默认不用（`hybridw` 仅作为实验分支）；下次要么加局
   到 1200+，要么先把 DangerNet 的监督信号改成「放铳结果标签」而不是「和牌张」。
