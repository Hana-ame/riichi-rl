# 混合对手 300 局闭环（bigBC 续训）

## 数据

`mixed_collect.py --deals 300`：学生池 = bigBC / 100h_v2 / bc_v1 / greedy / call_first
混战，教师 = greedy_tenpai 打 47 槽标签 → **79,394 样本**。

## 训练

从 bigBC（val 0.9839）续训 2 epochs（128ch/5blk，lr 3e-4）：val_acc 0.979（低于 bigBC 0.984）。

## 评测

| 口径 | teacher47_mixed | 100h_v2 对照 |
|---|---|---|
| `eval_hanchan` 80 局（4×同模型 vs greedy 同配置） | **局和牌 22/80 = 27.50%（座位≈6.88%）** | 33.75%（8.44%） |
| 同池审计 60 局/席（单席 vs 3 greedy） | 听牌 **30.0%**、座位和牌 **6.7%**、放铳 **8.3%** | 30.0%/6.7%/8.3% |

## 结论

- 混合对手数据 + 2 epochs：**没有改善**——同池指标与 100h_v2 完全相同（6.7%/8.3%），
  eval_hanchan 反而从 33.75% 降到 27.50%；
- 「异质对手数据不足」假设被否证：**换数据分布仍无法越过 6.7–10.94% / <15% 门槛**；
- 根因指向「47 槽 BC 目标 + 单机数据量」上限，而不是对手分布；下一步要见效只能
  换训练目标（RL 奖励/搜索）或外部强模型蒸馏（mahjonglm 需授权）。
