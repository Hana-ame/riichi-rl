## 1. hongdp/LLM_Mahjong —— 唯一同时做到「纯 RL」和「竞技场」的开源项目

**为什么最贴题**：它的 README 明确分两条线：

- **人类先验线**：Tenhou 牌谱行为克隆（bc49）→ RL。**这条违反我们的铁律。**
- **纯血线（Pure lineage）**：AlphaZero 式，**零人类数据、零外部模型作为训练信号**，
  从随机初始化学出全部技能栈。人类/教师模型只当标尺，**永不当冠军、永不进对手池**。

**纯度约束（他们的措辞，值得抄进我们的规则）**：

> 零人类牌谱、零外部模型（含 bc49/Mortal）作为训练信号；
> 允许模拟器先知信息只进优势/critic 估计；
> 允许按学习者可见起手的课程。
> 人类/教师模型是标尺 only —— never champions, never opponents in its pool;
> scenario curricula are permanently rejected; leagues of its own frozen
> snapshots and EMA self-anchors count as pure.

### 1.1 他们的纯血线跑到了什么程度（这是最有价值的部分）

**结论：$200 预算内没能达到 bc49/Mortal 水平，且他们把失败量化了。**

- 最好成绩：`exp88_Q1x` 对 bc49 单局配对 share **0.4568 ± 0.0035**
- 达成判定（他们定的）：单局配对 share ≥ 0.50 **且** 半庄头对头 ≥ 0.50（n ≥ 1,200）
- 缩放曲线：**对数线性 ≈ +1.5–2 pp 每倍增局数**，同配方续训在 0.45–0.46 渐近
- 成本：Rust 引擎 + RTX 2000 Ada ≈ 575 局/s，每百万局 $0.07
- 他们自己给的可行性预估：**$200 内达 bc49 平手概率 10–20%**，达到 M1(0.40) 约 50%

**这条缩放曲线对我们极其重要**，直接回答用户问的「纯 RL 从零学麻将要多少局才收敛」：

> 同配方从零训练，**32M–64M 局**才接近 0.46，且渐近线约 0.45–0.46。
> 要到 0.50，按 +1.5–2pp/倍增，**需要 16M→32M 局（约 $50–100 GPU）**
> 或「尚不存在的新杠杆」。

### 1.2 七类算子全部量过，全部判负或中性（这是最省钱的教训）

他们在纯血线上逐个预注册地测过：

| 算子 | 结果 |
| --- | --- |
| 半庄顺位/placement 目标 | ✗ |
| 价值方法（DQN/Double DQN ×4） | ✗（四战四负） |
| PBRS | ✗ |
| 反事实 rollout 优势 | 中性 |
| PSRO / best response | 中性（对冻结模型的最佳响应打不动） |
| 熵正则 / QRE / KL 磁铁 | **唯一为正（+1.0 pp）** |
| 搜索式改进算子（单步/多步） | ✗（回滚噪声 ≫ 模式差） |
| 非传递性 | **未观察到**（族外梯子传递、族内头对头稳定 0.50） |

**他们的诊断**（这段话值得逐字抄进我们的设计文档）：

> 平台是「低质量均衡」——双方缺同一项多步技能，均衡求解器造不出技能；
> 卡点在 **MDP 层面的信用分配**。

以及为什么搜索/危险度头这类「人类技巧」没用：

> 一次放铳吃掉几十次「预测安全」弃牌的收益；公开信息下待张预测天花板低。
> **危险度感知不是杠杆。**
> 留下的「安全牌」在真立直来时并不安全，牌效损失却是确定的。

> ⚠️ **这条对我们是坏消息但必须说**：他们用行为克隆起步的模型才学出防守链，
> 纯血从零的模型学不出。换句话说，**人类先验可能确实是必需的**。
> 但这不构成放弃纯 RL 的理由——只说明**要预期低很多的天花板**。

### 1.3 他们的评测协议（直接可抄）

> **评测协议：终审一律 T=0 + 族外梯子 + 半庄 n≥300；
> T=1 族内曲线不得单独下结论。**

「duplicate arena」（配对牌山）的规模刻度：

- 单局配对牌山：**两段 ≥20k 对**才算数
- 半庄头对头：**n ≥ 1,200 场**
- 梯子 Elo：13 个锚点，每锚 200 对

这比我写的「≥400 局 + 配对 t 检验」严格得多，**应当采纳他们的刻度**。

### 1.4 他们的工程约定（值得抄的两条）

1. **口径更正要留痕**：他们发现「接管类探针的标准误须按局聚类，
   原逐决策口径低估约 2×」——正是我在 ARENA.md 里担心的 cluster-robust 问题，
   他们踩过并量化了。
2. **实验必须预注册**：每个 run 启动前写 EXPERIMENT.md（目的/方法/成功标准），
   收尾补结果。判负也写进去。

## 2. Equim-chan/Mortal —— 算分与工程的黄金参考

- Rust 引擎 + 深度 RL，**1570★**，AGPL-3.0，2025-09 仍活跃
- 现状强度：天凤/雀魂顶级，与人类高段持平
- 官网 <https://mortal.ekyu.moe>
- 对我们的价值：
  - **算分实现的权威参考**（我们已用它验证过 110 格点数表 + 符模型）
  - Rust 引擎的性能路线——他们做到 575 局/s，我们现在 18 局/s

⚠️ **注意**：Mortal 是**人类打谱蒸馏 + RL**，其权重与数据受 AGPL + 「不得再分发」约束。
我们只能**读它的规则/算分实现**，不能拿它的模型当训练信号（那会破坏纯度）。
