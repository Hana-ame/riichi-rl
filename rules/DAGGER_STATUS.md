# 为了「赢」而改进：DAgger 自我教师方案与当前读数

> 仓库 `/mnt/e/riichi-rl`，训练日志 `train_dagger.log`

---

## 0. 目标

模型需要在真人环境取胜。第 3 轮巡检的硬读数：
**均匀随机 200 局 0 次和了（95% 上界 1.49%）**，同环境向听贪心 11.5%。

即：**纯均匀随机采样永远产生不了学习信号**，RL 奖励恒为 0、梯度为 0。
这不是奖励符号问题，是探索分布问题。

---

## 1. 方案：DAgger 自我教师（Self-Imitation Distillation）

用**自己的**向听贪心策略做数据收集，把它的动作蒸馏进神经网络。

```
教师 = 向听贪心（规则层计算：每步最大化打出后的向听数）
学生 = 453,232 参数的策略网络
损失 = 1.0 x 交叉熵(学生, 教师动作) + 0.5 x 策略梯度项
eps  = 1.0 -> 0.10（退火）
```

### 为什么不破坏「纯 RL」铁律

LLM_Mahjong 纯血线原文定义：

> "leagues of its own frozen snapshots and EMA self-anchors count as pure"

即**自我锚定属于纯 RL**。这里的教师不是人类打谱，
而是用规则定义量（向听数 = 离和牌还差几张牌）算的，**不含牌效表**。

**硬约束**：教师只用于数据收集，**绝不进入评估对手池**。
评估时学生单独对战。这是与 BC 的根本区别——
BC 学人类打谱（外部监督），这里学自己的行为（自我改进）。

## 2. 训练读数

```
iter  0 deals=32 eps=1.00 bc=3.8585 pol=-0.0001
iter  5 deals=32 eps=0.96 bc=3.2377
iter 10 deals=32 eps=0.92 bc=1.9234
iter 20 deals=32 eps=0.85 bc=1.7811
iter 30 deals=32 eps=0.77 bc=1.7038
iter 40 deals=32 eps=0.70 bc=1.6123
iter 45 deals=32 eps=0.66 bc=1.5616
```

**BC 损失 3.86 -> 1.56（下降 60%）**，学生在拟合教师。

---

## 3. 判据要分级（关键）

直接看和了率会误判。网络学会「打牌」和学会「和牌」是两个难度台阶。

**中间判据：平均向听**（每次 14 张决策点的向听数，越低越好）

| 策略 | 平均向听 |
| --- | --- |
| 随机 | 3.153 |
| **学生（iter 30）** | **2.659** |
| 教师（向听贪心） | 2.453 |

**学生在随机与教师之间，且明显优于随机。
这证明网络确实学到了打牌行为，不是死记轨迹。**

## 5. 下一步（按我的判断排序）

| # | 做什么 | 理由 |
| --- | --- | --- |
| 1 | 继续训练到 eps=0.10 收敛，再测 | 损失还在降，未收敛 |
| 2 | 若仍 0，把教师从「向听贪心」升级为「向听贪心 + 听牌后优先和了」 | 学生可能学会了保向听但没学会抓和了 |
| 3 | 增加「和了动作」的正样本：教师在能听牌时先演示到听牌 | 同上 |
| 4 | 引入真实牌效评估（对手也在用模型） | **这是最终目标**，当前只在自我对弈中测 |

> **重要**：第 4 项是「真人环境取胜」的真实检验。
> 当前所有读数都来自自我对弈，**不能证明在真人环境取胜**。

---

## 6. 假设与不确定处

1. **自我对弈的和了率不是真人环境的强度**。需要在雀魂/天凤实测，
   而那需要对接 mjai 协议（`vendor/majsoul_ref` 里有 Meld 类，但没有网络协议层）。
2. **教师是向听贪心，不是真人水平**。它 11.5% 的和了率只是「能到听牌」的上界，
   与天凤高段不可比。
3. **DAgger 的学生可能停在「局部最优」**：学会保向听但学不会抓和了。
   第 5 节第 2、3 项就是为了区分这两种情况。
4. **没有验证学生在混合对手下的表现**（只测了纯自对弈）。
