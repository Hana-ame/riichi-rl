# 混合代码-模型 Agent：代码算向听 + 模型决策（2026-11-05）

> 用户建议：「混合代码的模型，比如打哪张牌向听多少用代码计算。」

## 做法（`hybrid_agents.py`）

`HybridShantenAgent` 包任意 47/54 槽自研 ckpt（架构/特征模式从 ckpt 自动推断）：

1. **打牌阶段**：对每个候选弃牌用 `ref_shanten` 算「打完后向听数」→ 选最小；
   平手时用模型对该弃牌的 logit 做 tie-break（模型仍参与牌风）；
2. **其它阶段**（立直/默听/和牌/吃碰杠/响应）：模型 masked argmax；
3. 和牌/荣和强制动作先走规则，避免漏和。

## 实测（同一张强参照桌，每版 20 局）

参照桌 = `teacher47_v3 / bc_v1_last / greedy_tenpai`，版本轮流坐 4 个座位。

| 版本 | 和牌率 | 场均得分 | 放铳率 |
|---|---|---|---|
| teacher47_v3（纯模型） | 0.0% | −1110 | 5.0% |
| **hybrid:teacher47_v3（代码+模型）** | **10.0%** | **−885** | 5.0% |
| bc_v1_last（人类牌谱教师） | 15.0% | −638 | 10.0% |
| from_games_v2（蒸馏） | 0.0% | −2420 | 25.0% |

- 同强桌下，混合 Agent 比纯 teacher47_v3 由 **0/20 → 2/20 和牌**、
  场均 −1110 → −885；放铳率持平。样本 20 局，只算方向性证据。
- 实时性：hybrid p99 3.79 ms / max 4.46 ms（见 `rules/REALTIME_2026-11-05.md`）。
