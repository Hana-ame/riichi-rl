## 2. manager 要求的三个动作空间检查

### 项1：弃听 / 全防进不进采样

```
场景计数: defend时刻=2146  giveup时刻=203

动作「出现在合法集合」次数:
   DISCARD 21649 | PASS 6338 | CHI 265 | PON 144 | ADD_KAN 46

   PASS 6116 | DISCARD 2309 | CHI 125 | PON 65 | ADD_KAN 12
   RYUUKYOKU 11 | NAGASHI 10 | MINKAN 2 | ANKAN 1
```

**结论：可达，不是硬 bug。**
弃听（RYUUKYOKU）合法 31 次、被选 11 次；全防场景出现 2146 次。

**但暴露了一个新事实：`TSUMO` 在合法集合里出现 0 次**（30 局随机采样），
`RON` 只出现 1 次。因为均匀采样根本到不了听牌。

**PASS 占选中动作的 68%（6116/8951）**——上轮已修的槽冲突之外，
均匀采样下 PASS 被选概率天然高于其他动作（响应阶段 PASS 是唯一合法动作）。

```

  弃牌动作含手上没有的牌: 0
```

## 3. shanten 语义改动的连带影响（决断三）

### 3-a：和了局末步 shanten 是否为 -1、奖励是否给足

**无法验证。**40 局向听贪心里只有 2 局「听牌后成功和了」，样本量不足。

### 3-b：会不会卡在听牌不出牌

这是 manager 提出的「最可能机理」。实测：

```
听牌决策点总数:              2781
其中 RYUUKYOKU(停手) 可用:     57   （2.0%）
```

**结论：机理不成立。**停手只在 2% 的听牌时刻可用，98% 的听牌时刻策略仍必须继续打牌。
所以「打散手牌扣分导致卡住」这条路径被数据否掉了。

## 4. 三项检查的合并结论

| 检查 | 结果 |
| --- | --- |
| 环境能产生和了 | **是**（自摸 + 放铳都正确结算） |
| 弃听/全防可达 | **是**（合法 31 次 / 场景 2146 次） |
| 弃牌集合裁剪 | **正确**（18763 点零错误） |
| 弃牌 Q 区分度 | **正常**（极差/|Q| = 1.47） |
| 听牌卡住机理 | **不成立**（停手仅 2% 可用） |

**唯一异常：随机策略 200 局 0 次和了，而向听贪心 60 局 35%。**

差异来自**打牌质量**：均匀随机打出的手牌从未接近听牌
（14 张决策点的向听分布 `{1:46, 2:339, 3:823, 4:477, 5:84, 6:3}`，**没有 0**）。

这不是 bug，是**均匀随机采样在麻将上的固有性质**：
每人只摸约 18 张牌，随机打牌凑不出和了型。

## 5. 这对「能不能学」的含义

经理判据说「随机 0% = 环境问题」。但对照数据是：
**同一环境、同一样本，向听贪心 35%。**

所以 0% 的成因是**探索分布**，不是环境也不是动作空间。

这带来一个现实约束：**纯均匀随机采样永远产生不了和了信号**，
而 RL 需要看到终局回报才能学习。

三种可行方向（按我的判断排序）：

| # | 方向 | 代价 | 我的评价 |
| --- | --- | --- | --- |
| 1 | **重要性采样 / 局部策略改进**：只在「接近听牌」的局面加大采样密度 | 实现复杂 | 最正统，但要处理分布偏移 |
| 2 | **DAgger 式教师混合**：用向听贪心做数据收集，策略做改进 | 破坏「纯 RL」吗？**不破坏**，只要教师不进入评估对手池 | 见下 |
| 3 | **提高单局探索质量**：用轻量启发式初始化/温度调度 | 便宜 | 见效最快但偏离 on-policy |

**关于方向 2 是否破坏纯 RL 铁律**：LLM_Mahjong 的纯血线定义里明确写了
「leagues of its own frozen snapshots and EMA self-anchors count as pure」——
**自蒸馏/自我锚定属于纯 RL**。用自己（不是人类）的向听贪心做探索引导，
与自我锚定同族。但**必须严格区分**：教师信号不得进入评估对手池，
否则就是变相 BC。
