# 版本天梯：V1→V2→…同池混战 + 「后版本必须强过前版本才过」（2026-11-05）

> 用户要求：「新版本 V1/V2/… 都在一起比；靠后的版本需要比靠前的版本强才能过。」

## 规则（`version_ladder.py`）

1. **所有版本同池**：每个版本都是参赛者，每局随机抽 4 个同场（同一牌山/座位随机），
   用净点数逐对更新 Elo；
2. **相邻版本晋级闸门**：统计同局净点数差（后版本 − 前版本）的均值与 95% CI：
   - **PASS**：点差 95% CI 下界 > 0（显著更强），且 Elo 未显著下滑
     （ΔElo ≥ −band，band≈2×Elo 标准误，避免用噪声判死）；
   - **FAIL**：点差显著为负（CI 上界 < 0）或 Elo 显著下滑；
   - **HOLD**：其余（点差跨 0 / 样本不足 / 两指标矛盾）——**不算过**，继续加局。
3. 样本要求：每对相邻版本同局数 ≥20 才判 PASS/FAIL，否则 HOLD。

## 回答「准确率提升、和了率却没起」

- 训练准确率（BC val_acc 83.9%→95.2%）是**决策模仿准确率**，验证集里 75% 是
  响应 PASS——这部分很好学；而**和牌率**取决于打牌质量、立直/和牌时机、
  终局信用分配，不是分类准确率的线性函数。
- 天梯 240 局里，v1→v2 和牌率都 2.9%（没升），v3 到 5.0%（升了 2.1pt），
  style 掉到 0.8%。**同池里四个都是弱模型互相喂局，整体和牌率本来就低**；
  在 600 局混合池（含规则强基线/BC 教师）里纯神经模型也只有 0–5%（bc_v1
  16.4%）。→ 结论：准确率不是瓶颈指标，**和牌率/点数才是**；下一步按
  §4 推进。

## 下一步（按优先级）

   修 BC 的分布偏移（当前 240 局里 v3 仅 12 胜）。

   先保和牌率再调风格（style_rl 的失败案例已证明短程 RL 会毁策略）。

   可加「本局和牌」辅助价值头（aux_tasks 已有 win 任务）。
4. 每轮升级都过本天梯闸门（PASS 才发布新版本），FAIL/HOLD 不发布。
