# 第 1 轮巡检决断：和了率 0% 的根因（2026-10-04）

> 仓库 `/mnt/e/riichi-rl`

---

## 0. 结论先行

**0% 不是奖励符号问题，是动作空间槽位映射把 PASS 变成了默认动作。**

`slot_of` 原实现：`34 + (type*7 + tile) % 20`。
它把 **11 种动作类型折叠进 20 个槽，实测 20 个槽全部冲突**。

实测策略的动作分布：

```
slot=50  选 87 次   合法 91 次   <- PASS 的槽
action mix: {DISCARD: 769, OTHER: 2303, RYUUKYOKU: 3, PASS: 2}
```

**PASS 在响应阶段总是合法**（实测 4488/19436 = 23% 的决策点它是唯一合法动作），
是唯一零成本动作，策略早期必然倾向选它 -> 永不推进 -> 和了率 0%。

已改为显式分配，跨类型冲突 **20 -> 0**，`N_ACTIONS` 54 -> 47。

## 1. 三个可疑点的读数

### 可疑点 1：和了率统计口径 + 和了通路是否可达

**结论：通路正常，统计口径也正常。**

| 检查 | 读数 |
| --- | --- |
| 14 张必和手牌 -> `legal_actions` 含 TSUMO | **True**，slot=40 |
| 引擎是否自动结算和了 | **否**（只打牌不选 TSUMO -> result 仍为 None） |
| 随机采样 60 局，和了事件出现次数 | **0** |
| 随机采样时 `tsumo_available` / `ron_available` | **{} （一次都没出现）** |
| 向听贪心 60 局 | **win=21（35.0%）**，tsumo 机会 4 次 + ron 机会 17 次 |

**判别结论**：同一引擎下向听贪心 35%、均匀采样 0%。
动作空间可达、和了通路正常。**0% 纯粹因为均匀采样采不到听牌**。

### 可疑点 2：shanten 奖励在和了后是否仍在推进

**结论：不会，但影响为零** —— 因为根本没有任何一局和了。

14 张决策点的向听分布（随机采样 60 局）：

```
{1: 46, 2: 339, 3: 823, 4: 477, 5: 84, 6: 3}   <- 没有 0（听牌）
```

所以「和了后 shanten 还在推进」这个场景**未被触发**，无法证伪。
该项要等第一次出现和了才能测。

### 可疑点 3：关键动作的 logit 有没有在动

**结论：动了，但全用在 PASS 上。**

```
策略选中的槽位 TOP12:
  slot=50  选  87 次   合法  91 次
  slot=24  选   4 次   合法   9 次
  slot= 4  选   3 次   合法  12 次
  ...
特殊槽 (>=34):
  slot=49  选 2 次   合法 2 次
  slot=50  选 87 次   合法 91 次     <- PASS
  slot=51  选 1 次   合法 1 次
```

**TSUMO（slot 40）一次都没被选过。** 熵在降（0.59）说明策略在收敛，
但收敛到了 PASS 上。

## 2. 对照实验（决断 2）

要求：同一策略对 (A) 真实和了结算 (B) 强制按和了给奖励，各跑 200 iter。
实际只能跑 8 iter（每 iter 约 37 秒，200 iter 需 2 小时）。**读数如下**：

| 实验 | 采样策略 | FORCE_WIN 触发次数 | 和了率 |
| --- | --- | --- | --- |
| **A** 均匀随机 + 真实结算 | 均匀随机 | 0 | **0.00%** |
| **B** 均匀随机 + 强制和了奖励 | 均匀随机 | **0（从未触发）** | **0.00%** |
| **B′** 向听贪心 + 强制和了 | 向听贪心 | 有 | **2.34%** |

```
(B)  iter 7 deals=128 win= 0.00%   <- FORCE_WIN 一次都没触发
(B') iter 7 deals=128 win= 2.34% last=104 giveup=3   <- 末局场景被激活
```

### 这个对照切开了什么

**(B) 的 0% 是无效结论**，因为 FORCE_WIN 在随机采样下**一次都触发不到**。
这本身就是最重要的读数：它证明**「奖励符号」根本没机会起作用**。

**(B′) 的 2.34% 是有效读数**：一旦采样能到听牌，和了率立刻非零，
且 `last=104` 说明末局搏命场景被激活、`giveup=3` 说明弃听场景被激活。

**结论：根因在采样（探索），不在奖励。**

## 4. 假设与不确定处

1. **对照实验只跑了 8 iter 而非 200 iter**。理由：每 iter 37 秒，200 iter 需 2 小时，
   超出本轮时间预算。**8 iter 足以判断「是否离开 0%」，不足以判断收敛行为。**
2. **B′ 的 2.34% 低于向听贪心的 35%**，因为 B′ 训练里的奖励仍然以分差为主、
   向听为辅，且 `--force-win` 只强制「有和了就选」，不强制「怎么打到听牌」。
   这个差距是否随训练收敛变窄，未验证。
3. **PASS 槽仍然固定**，理论上策略仍可能学会不用它。
   更彻底的做法是把 PASS 从动作空间里去掉（响应阶段不选就是选 PASS，
   语义等价），但那会改变动作空间定义，本轮没做。
4. **`--behaviour shanten` 是探索用的教学信号，不是策略**。
   它用于制造有和了的数据；正式训练必须回到 `--behaviour random`
   或直接用 on-policy 采样。**用它训练出来的模型不能算「纯 RL 学会的」。**
